# Number Bonds

A number bonds display for 5-year-olds, made for group learning on a classroom screen that the teacher controls.

Open `index.html` in a browser. There's no build step and nothing to install.

## Activities

- **Explore**: steps through every bond for the chosen whole in a part-whole diagram (whole on top, two parts below), with the matching number sentence.
- **Missing part**: hides one part. The class works it out, then the teacher presses Reveal.
- **All bonds**: shows every pair for the whole side by side. Click one to show it big.

## Teacher controls

- **Bonds to**: the whole, from 2 to 10.
- **Show as**: Dots (default), Ten frame, or Numicon-style plates (drawn for this app in the usual Numicon colours, not official artwork).
- **Numerals**: show or hide the numbers so children count from the picture.

Keyboard: arrow keys step through bonds, Space reveals, N skips, 2 to 9 (and 0 for 10) set the whole, V changes the view, F toggles full screen.

Settings are remembered in the browser's local storage.
